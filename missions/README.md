# Índice de Missions

Cada Mission é uma pasta com esta estrutura:

```
missions/NNN-nome-curto/
├── README.md      enunciado: o caso, o contexto, o que se espera
├── CRITERIOS.md   critérios de aceite, públicos
├── dados/         insumos, quando houver
└── entrega/       o que você preenche
```

## Convenção de nome

`NNN-nome-curto`, com `NNN` sequencial em três dígitos. O número não indica dificuldade nem ordem obrigatória — indica ordem de publicação.

## Ritmo

4 a 6 Missions por ano no piloto.
