# Missions — The Plumbers

Casos reais de engenharia de dados e engenharia agêntica. Você resolve, entrega no Git, e recebe uma revisão contra um critério escrito.

Este repositório contém **os enunciados**. A revisão, a rubrica e as notas ficam em um repositório privado — o que você vê aqui é tudo que você precisa para resolver, e nada do que decide a nota.

---

## Como funciona

1. **Comece pelo template.** Clique em **`Use this template`** no topo desta página. Você recebe um repositório novo, seu, sem vínculo com este.

   > Não use *Fork*. O template gera um repositório limpo, com o primeiro commit sendo o seu — que é o que faz o resultado servir como portfólio.

2. **Resolva a Mission.** Cada Mission tem um `README.md` com o caso e um `CRITERIOS.md` com o que será avaliado. Os critérios são públicos de propósito: você não deveria adivinhar o que é uma boa entrega.

3. **Entregue.** Abra uma issue **neste repositório** usando o template *Entrega de Mission*, apontando para o seu repositório. Ver [`ENTREGA.md`](ENTREGA.md).

4. **Receba a revisão.** O parecer volta na sua issue. Se aprovado, vira um **Evidence Card** publicado no espaço *Evidências* da comunidade — um registro de que o trabalho foi avaliado, e por qual critério.

---

## O que é avaliado

Toda Mission é avaliada contra critérios explícitos, publicados junto com o enunciado. Não existe critério secreto.

O que fica privado é o **gabarito** e as **notas de revisão** — pelo mesmo motivo que uma prova tem gabarito separado: se o gabarito é público, o exercício deixa de exercitar.

## Quem pode entregar

Membros **BUILDERS** e **OPERATORS** do The Plumbers.

Os enunciados são públicos e qualquer pessoa pode resolvê-los por conta própria — inclusive quem ainda não é membro. O que a assinatura dá é a **revisão**: o parecer contra a rubrica, o Evidence Card e o registro na comunidade.
